# My First PR Practice

A tiny practice repo for learning the GitHub Pull Request workflow: fork/branch, commit, push, open a PR, and merge.

## What this repo is for

- Practicing `git` and `gh` commands
- Trying out branches, commits, and pull requests
- Learning how a PR review and merge works end to end

## Getting started

```bash
git clone https://github.com/<your-username>/my-first-pr-practice.git
cd my-first-pr-practice
```

Make a change on a new branch, commit it, push, and open a PR against `main`.
